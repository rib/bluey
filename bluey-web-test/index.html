🫀 Bluey Web Bluetooth Heart Rate Monitor Test

About this test:
This test demonstrates the Bluey library's Web Bluetooth backend by connecting to a Bluetooth LE heart rate monitor and displaying real-time heart rate measurements and RR intervals.

Requirements:

  • A Bluetooth LE heart rate monitor (chest strap, smartwatch, etc.)
  • Chrome, Edge, or another browser supporting Web Bluetooth
  • HTTPS connection (required by Web Bluetooth API)
  • User gesture (click the button below) to initiate Bluetooth access
Note: Web Bluetooth requires user interaction to access devices. When you click the test button, your browser will show a device selection dialog. Choose your heart rate monitor from the list.

Click the button below to start testing. The log will show all communication with your heart rate monitor.
